# DuoGrid
пошаговая стратегия на двоих, сделанная на Unity, главное отличие которой битва на изменяемых полях с катастрофами, мутациями и всяким разным дополнениями. За разных персонажей, с разными таллантами и механиками.
Каждый игрок управляет магом, который может менять клетки на полях.
Главная фишка - финиш ставит тоже игрок, но финиш максимум только один на всю карту.

## Всякие механики
- **Огонь**: это клетка которая может убрать любую не защищенную растительность.
- **Грибная катастрофа**: Событие при котором появляются грибы, с возможностью смутировать.
- **Грибы, Катусы**: по факту одна из разрастающихся механик на момент написания. Выживания, Мутации, Тактики.
- **Таланты**: Возможность выбора усиления после каждого раунда.

## Сама игра
Игра проходит до момента победы игрока n-ое кол-во раз. Выбираемое в настройках игры.
1. При запуске стандартной игры, каждый игрок выбирает себе Персонажа.
2. После выбора выбираются начальные клетки и предметы игроков.
3. Выбор талантов. Таланты могут выпасть рандомные до определённых уровней на каждого героя.

## Справка

Движение персонажем 1 в обычном режиме
идет через кнопки WASD.
В своё время персонаж два ходит используя стрелочки.
Оба игрока во время своего хода могут нажать на кнопку C и начать строить.

Финиш может поставить любой игрок но только один и на платформу врага.

Еще одна из механик игры то что кто бы не построил поле любой игрок будет взаимодействовать с этим полем наступив на него.
_________________________________
Механики полей
_________________________________

Damage Уронное - наносит урон игроку.

Finish Финальное - Дает игроку одно очко победа и телепортирует игрока в точку старта.

Poison Ядовитое - Отравляет игрока, после чего когда пройдет 4 хода игрок получит 3 урона.

Antidote Противоядие - Убирает эффект яда с игрока.

Wall стена - блокирует перемещения игрока

Capsule капсула - может модифицировать некоторые клетки

_________________________________
Механики
_________________________________

В игре есть Валюта которая тратится на действия движения - Такты
чтобы их получить нужно ничего не делать кроме как нажать на пробел. Аккуратно при нажатии стоя на клетке клетка будет использоваться, таким образом можно накопить шагов и сделать за один свой ход много движений.

В игре есть механика Катастроф

v1.62 - грибное мутирование
на карте появляются грибы, который мутируют в одного кактуса когда рядом с одним грибом еще 2 или 3 таких же.
 Кактус наносит на клетках вокруг себя, вокруг места появления кактуса все блоки становятся обычными.
В этой версии только кактус может получить так называемый модификатор - капсулы. и после трёх ходов с этим модификатором от любого игрока. кактус проростает в ходящего маленького кактуса.
Он делает так - что когда касается игрока за которым он ходит, этот игрок теряет возможность ставить любые клетки(кроме предметов) на 3 хода, сам кактус в этот момент станится. Этого кактуса можно убить только когда он наступит на огонь.

Новые предметы - гуава бум
взрыв клеток в радиусе плюсика, не считая клетку  на которой он стоит, на этих местах появляется огонь который пока что остаётся на всю игру.

v1.92 - добавленн кровавый дождь, кровавая луна, выбирание предметов игроками, выбирание клеток игроками, выбирание персонажей в виде обычного мага и техника. Добавленны шейдеры, кровокрады и исправленны многие баги.
Добавленны настройки сессии, через главное меню, пока только количества побед и громкости музыки.

Кровокрады - новые враги, который воруют предметы у игрока и убегают через появляющийся портал.

Техник, персонаж кидающий специальное устройство которое запрещает клетке использовать свои свойства.

Аптечка: предмет-клетка при наступлении на которую наступившему добавляется +1 здоровье. По 4 заряда на одну аптечку.
